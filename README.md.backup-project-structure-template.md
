## Intended Use

- `docs/`: design basis, safety rules, requirements, and CAN message definitions.
- `firmware/`: embedded software for the vehicle ECU and dashboard.
- `hardware/`: mechanical/electrical packaging documents and BOM assets.
- `simulations/`: modeling and behavioral validation.
- `scripts/`: build, flashing, and validation automation.
- `config/`: system parameters, DBC files, and environment templates.
- `tests/`: unit/integration/hardware validation assets.
